# 🎉 版本 v1.0.0-beta.5 更新日志

## QcClip 版本更新

### 新增

- **跨设备同步**：支持通过局域网直连或 WebDAV 在多台设备间同步剪贴板内容。同一网络下可自动发现附近设备，输入对方显示的 6 位配对码即可添加；不同网络可借助 WebDAV 生成临时配对码远程添加。内容按目标设备端到端加密，WebDAV 暂存最近上传的内容，对方离线时可稍后拉取。支持自动或手动上传与拉取，可按设备分别设置同步范围和内容格式，也可通过标题栏按钮或全局快捷键上传最新内容、拉取新内容。接收的内容默认同时写入系统剪贴板，可直接粘贴。
- **数据转移与备份**：数据管理新增“数据转移与备份”，可按收藏、历史、图库和应用设置导出数据包，收藏支持按标签筛选，历史支持按天数筛选。数据包可保存到本地或 WebDAV，并可设置独立密码加密；导入前可预览内容并选择合并或替换，同时自动备份本机数据。
- **贴到屏幕与拆词**：条目可贴到屏幕成为独立的置顶便签，支持文本、富文本、图片和文件；便签支持编辑文本、自选颜色、调整透明度和折叠，位置与状态在重启后自动恢复。拆词可将文本按词或按字拆分，自动识别链接、邮箱、路径和日期等整体内容，选中后可按多种拼接方式复制或粘贴。两项功能可通过右键菜单、条目操作按钮或窗口内快捷键使用，贴到屏幕默认快捷键为 **`Alt + T`**。
- **多选拖放**：多选条目后可直接拖放到目标窗口，所选内容会合并后一次放入。
- **格式粘贴快速切换**：托盘菜单新增“格式粘贴”开关，也可在快捷键设置中为其绑定全局快捷键。关闭后粘贴时优先只粘贴纯文本，指定格式的粘贴操作不受影响。
- **鼠标左键与中键行为统一**：左键与中键共用同一组点击行为选项，均可设置单击或双击执行粘贴、纯文本粘贴、复制、切换选中、置顶或收藏，中键新增双击支持；原有的中键设置会自动沿用。
- **状态边框线**：条目显示设置新增“状态边框线”，可分别为置顶条目和已粘贴条目启用边框线，便于区分条目状态。
- **悬停预览延迟**：支持自定义鼠标在条目上停留多久后显示预览，设为 0 毫秒时立即显示。
- **预览窗口缩放**：支持在界面缩放的基础上，单独调整悬停预览中文字、提示和文件信息的大小。

---

### 优化

- **粘贴按键释放**：优化粘贴时的按键释放处理，降低修饰键在粘贴后保持按下状态、造成按键锁定的风险。
- **焦点管理**：优化 QcClip 多个窗口之间的焦点管理，点击或拖拽主窗口时不再抢夺其他窗口的焦点，减少焦点丢失或焦点落到错误窗口的问题。
- **设置窗口分类**：重新整理设置窗口的分类与页内分组，相关选项更加集中，便于查找。

---

### 修复

- **粘贴到本程序窗口**：修复无法将内容粘贴到 QcClip 自身窗口（如文本编辑窗口）的问题。
- **主窗口输入框粘贴目标**：修复主窗口输入框处于聚焦状态时，通过快捷键粘贴的内容被发送到上一个窗口的问题。
- **粘贴后列表整表刷新**：修复粘贴后主窗口列表全量刷新的问题，现仅更新受影响条目的粘贴次数与热度。
- **纯文本粘贴后窗口隐藏**：修复在主窗口执行纯文本粘贴后，窗口未自动隐藏的问题。
- **材质下浮层发灰**：修复开启系统材质时，标签面板、悬停信息条和浮动工具栏等半透明浮层出现模糊重叠与发灰的问题。
- **整屏滚动设置**：修复系统滚轮设置为“一次滚动一个屏幕”时，轻滚一下列表就跳到首尾的问题。
- **旧版数据迁移**：修复系统临时目录位于内存盘等特殊磁盘时，旧版数据迁移失败的问题。
- **无窗口进程应用过滤**：修复无窗口的后台进程无法添加到应用过滤的问题，现可直接输入 `.exe` 进程名或完整路径添加规则，无需应用正在运行。
- **HTML 图文预览截断**：修复自适应行高下，HTML 图文混排内容的预览显示不完整的问题。
- **Windows 10 圆角锯齿**：修复 Windows 10 下窗口圆角边缘出现锯齿的问题。
- **多余滚动条**：修复列表内容不足一屏时仍显示滚动条的问题，减少视觉干扰。
