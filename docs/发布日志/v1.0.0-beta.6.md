# 🎉 版本 v1.0.0-beta.6 更新日志

## QcClip 版本更新

### 新增

- **快捷收藏**：新增快捷收藏全局快捷键（默认未绑定），可在任意应用中一键收藏当前选中的内容。选中文本时会打开编辑器，可在保存前修改内容和添加标签，并保留原始格式；图片、文件等非文本内容直接加入收藏。内容已存在时自动合并到原条目，不会重复记录。没有选中内容时，可按设置打开空白编辑器新建收藏。
- **托盘图标与托盘行为设置**：常规设置新增“隐藏托盘图标”开关，隐藏后可通过全局快捷键打开主窗口；支持分别设置托盘图标的左键和右键行为，可选择显示/隐藏主窗口、打开托盘菜单、打开设置、直接打开指定页面，或切换剪贴板监听、全局快捷键监听和格式粘贴。
- **图库按使用频率排序**：图库新增“使用频率”排序方式，常用图片排在前面，方便快速找到。

---

### 优化

- **Emoji 加载性能**：彩色 Emoji 改为在 CPU 上合成渲染，单个 Emoji 的绘制耗时约降低 90%，修复切换到 Emoji 页面时卡顿的问题。
- **便捷粘贴窗口阴影**：为便捷粘贴窗口增加阴影效果，与背景内容的区分更加清晰。

---

### 修复

- **便捷粘贴崩溃**：修复关闭便捷粘贴窗口时可能导致应用崩溃的问题。
- **备注窗口无法打开**：修复无法打开条目备注窗口的问题。
- **图片重复记录**：修复部分应用复制图片时分多次写入剪贴板，导致同一张图片被重复记录的问题。
- **输入法候选词隐藏主窗口**：修复在主窗口输入框中输入时，点击输入法候选词导致主窗口被隐藏的问题。
- **Shift 滚动失效**：修复按住 Shift 时无法滚动主窗口列表和便捷粘贴列表的问题。
- **跨屏呼出窗口尺寸异常**：修复从高缩放比例屏幕切换到低缩放比例屏幕后，首次在屏幕边缘呼出窗口时尺寸异常的问题。
- **回到顶部首帧跳跃**：修复显示窗口并自动回到顶部时，列表首帧出现跳跃的问题。
- **新增标签行不显示**：修复没有任何标签时，在标签管理窗口点击新增标签按钮后不显示新增行的问题。
